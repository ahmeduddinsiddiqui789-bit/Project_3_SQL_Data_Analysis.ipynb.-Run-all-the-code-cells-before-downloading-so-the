# Project 3: SQL Data Analysis

## Overview
This project analyses an order dataset using SQL.
The goal is to extract useful business insights
through filtering, sorting, grouping and aggregation.

## Dataset
The dataset contains 1,200 order records and 14 columns,
including product, quantity, unit price, payment method,
order status, referral source and total price.

## Tools Used
- Python
- Google Colab
- SQLite
- SQL
- Pandas

## SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- HAVING

## Key Analysis
- Order counts by product
- Total order value by product
- Average order value
- Payment method analysis
- Order status analysis
- Referral source analysis
- Monthly order activity

## Key Findings
- 1,200 order records were analysed.
- Printer had the highest order count, at 181.
- Chair had the highest total recorded order value,
  approximately 195,620.11.
- Online was the most frequent payment method,
  with 258 orders.
